REST API Endpoints

All endpoints are served from http://127.0.0.1:8000/api/

GET /api/students/ List all students
POST /api/students/ Create a new student
GET /api/students/{id}/ Retrieve one student
PUT /api/students/{id}/ Full update
PATCH /api/students/{id}/ Partial update
DELETE /api/students/{id}/ Delete a student

Student Data Model

Field Type Notes
student_id CharField (20) Unique institutional ID — e.g. STU-001
full_name CharField (150) Student's complete name
department CharField (100) Academic department name
year IntegerField Choices: 1 = First … 4 = Fourth Year
email EmailField Unique — used as contact identifier
phone_number CharField (20) Includes country code if applicable
address TextField Full residential / mailing address
created_at DateTimeField Auto-set on creation (read-only)
updated_at DateTimeField Auto-updated on every save (read-only)
